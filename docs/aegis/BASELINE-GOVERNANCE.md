# Baseline Governance

The attached assignment PDF is the product requirement authority. The repository began empty, so this implementation owns the HTTP API, orchestration state, parsers, generators, retrieval adapter, research adapter, and local artifact registry.

Hard boundaries:

- Generated DOCX and PPTX files remain native and editable.
- The local demo works without paid credentials or an external vector database.
- External providers are optional adapters, never hidden runtime requirements.
- The sample flow is predictable and verifiable locally.
- No migration or deletion is in scope for this greenfield project.
